# 01 产品摘要与MVP总览
> **一句话产品定义**  
> 一个帮助建筑学学生和建筑从业者发现职业可能性、理解能力迁移方法，并向成功转行者获得针对性建议的平台。

## MVP要解决的两个核心问题
- 方向发现：我学过建筑、做过建筑，但我不知道还能去哪些行业，也不知道哪些行业愿意接受建筑背景。

- 路径行动：当我选中一个方向后，我不知道需要补什么能力，CV、作品集和面试应该如何准备。

## MVP核心闭环
> **1.** 用户从自身状态、能力或目标行业进入网站。
>
> **2.** 查看职业方向、行业接受度和建筑能力迁移关系。
>
> **3.** 阅读匿名、结构化的真实转行路径案例。
>
> **4.** 获得该方向的CV、作品集、面试和招聘准备建议。
>
> **5.** 收藏方向，或预约已经走过这条路径的人进行付费文字/视频咨询。

## MVP交付规模建议
| 首批转行方向 | 结构化案例 | 认证咨询者 | 有效招聘岗位 |
|---:|---:|---:|---:|
| 8–12 | 30–50 | 10–20 | 30–50 |

## 最小功能集合
| **模块**     | **MVP必须完成**                            | **暂缓**             |
|--------------|--------------------------------------------|----------------------|
| **方向发现** | 转行方向地图、筛选、方向详情               | 复杂AI职业测评       |
| **路径知识** | 匿名案例、能力迁移、CV/作品集/面试指南   | 完整在线课程         |
| **市场验证** | 适合建筑背景的招聘信息                     | 完整招聘投递系统     |
| **人与服务** | 咨询者主页、文字咨询、第三方视频预约、支付 | 平台内实时音视频     |
| **用户工具** | 登录、收藏、订单、资料上传                 | 大型社区与动态信息流 |
| **平台运营** | 内容编辑、审核、隐私与举报处理             | 自动化内容抓取发布   |

# 02 背景、问题与机会
## 现有内容供给的价值与缺口
公众号、小红书和个人博主已经证明“建筑转行”具有持续内容需求，也积累了大量采访、经验帖和职业讨论。但这些内容通常以单篇文章或个人叙事存在，用户需要自行搜索、判断和拼接，难以快速回答“我能转什么、为什么适合、接下来怎么做”。

| **现状**               | **用户遇到的问题**                   | **产品机会**                       |
|------------------------|--------------------------------------|------------------------------------|
| **案例分散在不同平台** | 搜索成本高，难以跨方向比较           | 建立统一方向地图和结构化索引       |
| **内容偏个人故事**     | 读完仍不知道哪些经验可复制           | 只提取转行方法、能力迁移和行动步骤 |
| **行业岗位描述抽象**   | 不知道企业是否接受建筑专业           | 关联真实招聘要求和专业接受度       |
| **作品集建议泛化**     | 不知道建筑作品如何改造成目标岗位作品 | 按岗位给出作品集结构和案例         |
| **咨询依赖私信**       | 匹配、信任、预约和支付成本高         | 认证咨询者、标准服务和交易保障     |

## 用户核心问题树
| **阶段**               | **用户问题**               | **平台应提供的答案**                 |
|------------------------|----------------------------|--------------------------------------|
| **不知道转什么**       | 建筑学还能进入哪些行业？   | 方向地图、适配度、典型岗位和进入路径 |
| **不知道是否适合**     | 我的建筑能力能迁移过去吗？ | 能力迁移词典、优势/短板和案例证据   |
| **不知道企业是否接受** | 专业不对口会被拒绝吗？     | 专业限制、企业类型、真实招聘要求     |
| **不知道怎么准备**     | 需要学什么、做什么作品？   | 能力缺口、学习任务、CV和作品集指南   |
| **不知道怎么表达**     | 面试如何解释建筑背景？     | 能力转译、项目故事和常见问题         |
| **需要个性化判断**     | 我的具体情况应该怎么走？   | 认证转行者的文字、视频或材料诊断     |

## 产品机会判断
> **关键差异化**  
> 本产品不是另一个“转行故事媒体”，而是把分散故事整理成可查询、可比较、可行动的转行路径知识，并通过咨询服务完成从信息到决策的最后一步。

# 03 产品定位与设计原则
## 品牌与产品定位
| **项目**       | **定义**                                                                       |
|----------------|--------------------------------------------------------------------------------|
| **品牌名**     | 建筑蟑螂互助会                                                                 |
| **产品副标题** | 建筑人转行案例与职业互助平台                                                   |
| **品牌隐喻**   | 建筑人经过高强度训练，具备很强的适应、学习和迁移能力，可以在多个行业继续生长。 |
| **核心口号**   | 建筑人到哪儿都能活。                                                           |
| **理性价值**   | 降低职业方向探索、能力转译和准备路径的成本。                                   |
| **情绪价值**   | 让用户知道自己不是失败或逃离，而是在迁移一套有价值的能力。                     |

## 产品原则
| **原则**                 | **产品要求**                                           |
|--------------------------|--------------------------------------------------------|
| **方法优先于故事**       | 案例重点回答“如何转”，不消费个人隐私和情绪经历。       |
| **事实优先于鼓励**       | 同时展示优势、门槛、困难和失败风险，不夸大转行可能性。 |
| **能力迁移而非否定过去** | 帮助用户把建筑经历转译成目标行业可理解的能力。         |
| **内容可比较**           | 不同案例使用统一结构，支持筛选和横向比较。             |
| **匿名公开、后台验证**   | 公开页面最小化身份信息；平台在后台完成真实性验证。     |
| **先行动、后扩展**       | MVP先打通发现—理解—咨询，不先做社区、课程和复杂AI。    |

## 价值主张
| **对象**       | **核心价值**                                       |
|----------------|----------------------------------------------------|
| **准备转行者** | 更快找到可能方向，判断适配度，并形成明确准备清单。 |
| **成功转行者** | 用可控时间分享经验、建立个人影响力并获得咨询收入。 |
| **企业招聘方** | 触达具有空间、研究、表达和复杂项目能力的候选人。   |
| **内容创作者** | 让优质采访获得更长生命周期和结构化传播。           |

# 04 目标用户与核心场景
## 用户角色
| **角色**           | **典型特征**                  | **主要目标**                   | **核心顾虑**                     |
|--------------------|-------------------------------|--------------------------------|----------------------------------|
| **探索者**         | 建筑学生、应届生或0–3年从业者 | 发现可能方向，避免盲目学习     | 选择太多，不知道什么适合自己     |
| **转行准备者**     | 3–8年建筑/景观/室内从业者   | 制定CV、作品集、学习和求职计划 | 沉没成本、收入下降、经验不被认可 |
| **转行者/咨询者** | 已进入目标行业并具备真实经验  | 分享路径并提供有边界的咨询     | 隐私暴露、无效提问、时间被消耗   |
| **内容运营**       | 平台编辑、采访者、行业志愿者  | 持续建设高质量路径知识         | 来源授权、事实核验、内容更新     |
| **企业招聘方**     | 愿意接受跨专业人才的团队      | 找到高迁移能力的候选人         | 候选人缺乏岗位语境和作品证明     |

## 典型用户画像
> **主用户画像**  
> 一名有建筑学教育或工作背景、对现有职业发展不满意，但不知道可以转向哪些行业、已有能力是否被认可，以及CV、作品集和面试应该如何准备的学生或从业者。

## 核心场景故事
| **场景**           | **一句话故事**                                                                           |
|--------------------|------------------------------------------------------------------------------------------|
| **从零探索**       | 工作四年的建筑设计师通过能力标签发现自己适合服务设计，并比较该方向的门槛与准备周期。     |
| **已有方向**       | 建筑硕士想转AI产品，通过方向页了解企业接受度、需要补充的能力以及第一份作品集应如何搭建。 |
| **以职位反推准备** | 用户看到一个接受建筑背景的用户研究岗位，并反向查看应如何改写CV和准备面试案例。           |
| **获得个性化判断** | 用户预约已从建筑转UX的咨询者，带着脱敏作品集讨论项目重构和求职节奏。                     |
| **分享经验**       | 成功转行者匿名发布路径案例，并设置自己可回答的问题和每月可接咨询数量。                   |

# 05 MVP范围与信息架构
## MVP目标
- 验证用户是否愿意用结构化路径内容替代分散搜索。

- 验证“能力迁移 + 行业接受度 + 求职材料准备”是否形成明显差异化。

- 验证用户是否愿意为成功转行者的针对性建议付费。

- 验证成功转行者是否愿意以匿名公开、后台认证的方式提供内容和服务。

## MVP不做什么
- 不承诺用户一定转行成功，不提供结果担保。

- 不建设大型社区、帖子流、关注关系和群聊。

- 不提供系统性录播课程或长期陪跑服务。

- 不自动生成完整CV或完整作品集。

- 不自建视频会议，不在首版开发实时聊天。

- 不建设完整招聘ATS，不代替企业收取简历。

- 不公开转行者的真实姓名、精确公司、精确薪资等非必要信息。

## 网站信息架构
| **一级入口** | **二级内容**                               | **用户任务**                   |
|--------------|--------------------------------------------|--------------------------------|
| **首页**     | 三种入口、热门方向、精选案例、咨询者、岗位 | 选择从方向、能力、案例或人开始 |
| **探索方向** | 方向地图、方向详情、对比                   | 知道可以转什么及门槛           |
| **转行案例** | 案例列表、案例详情                         | 学习真实路径和可复制方法       |
| **能力迁移** | 建筑能力词典、岗位映射                     | 把建筑经验翻译成目标岗位能力   |
| **招聘机会** | 岗位列表、岗位详情/外链                   | 验证市场需求并反推准备         |
| **找人聊聊** | 咨询者列表、个人主页、服务下单             | 获得个性化建议                 |
| **个人中心** | 收藏、订单、资料、咨询记录                 | 管理自己的探索和交易           |

## 首页三大入口
| **入口**                 | **用户文案**             | **进入结果**                   |
|--------------------------|--------------------------|--------------------------------|
| **我不知道可以转什么**   | 从我的经历与擅长能力出发 | 方向推荐列表与比较             |
| **我已经有目标方向**     | 看看行业是否接受建筑背景 | 方向详情、门槛、案例和准备清单 |
| **我想找走过这条路的人** | 带着具体问题找前辈聊聊   | 咨询者筛选与预约               |

# 06 功能需求
## F1｜转行方向地图
目标：帮助不知道转什么的用户快速看到建筑背景可能进入的行业，并理解每个方向的真实门槛。

| **功能点**   | **需求说明**                                                                     | **优先级** |
|--------------|----------------------------------------------------------------------------------|------------|
| **方向分类** | 按数字产品、设计创意、商业与咨询、地产与城市、技术与研究、公共与教育等分类。     | P0         |
| **条件筛选** | 按当前身份、建筑年限、擅长能力、是否愿意做作品集、是否愿意从初级岗位开始筛选。   | P0         |
| **方向卡片** | 展示岗位简介、建筑适配度、专业接受度、作品集要求、准备周期和案例数量。           | P0         |
| **方向详情** | 展示工作内容、可迁移能力、能力缺口、进入路径、求职材料、相关案例/岗位/咨询者。 | P0         |
| **方向对比** | 用户最多选择3个方向，对比门槛、准备成本、作品集和岗位机会。                      | P1         |

## F2｜转行路径案例库
目标：将公开采访和用户分享整理成匿名、可比较、可行动的“路径案例”，而不是个人传记。

| **功能点**   | **需求说明**                                                         | **优先级** |
|--------------|----------------------------------------------------------------------|------------|
| **案例列表** | 支持按起点、目标岗位、年限、准备方式、是否需要作品集、是否脱产筛选。 | P0         |
| **案例摘要** | 突出起点→目标、转行契机、准备周期、关键迁移能力和进入方式。          | P0         |
| **案例详情** | 按起点、契机、迁移、补充、材料、面试、结果七部分呈现。               | P0         |
| **来源标记** | 标记平台原创、用户投稿、授权转载或外部摘要，并提供原文链接。         | P0         |
| **隐私控制** | 默认匿名；敏感信息以区间或类别展示；发布前通过授权和隐私审核。       | P0         |
| **关联内容** | 案例关联目标方向、能力标签、招聘岗位和可咨询者。                     | P1         |

## F3｜建筑能力迁移词典
目标：把建筑专业语言转译为企业能够理解的通用能力，并关联相应岗位。

| **建筑经历/能力**   | **可转译能力**                     | **示例目标岗位**     |
|----------------------|------------------------------------|----------------------|
| **场地与人群调研**   | 用户研究、案头研究、信息采集与洞察 | 用户研究、咨询、产品 |
| **功能与动线分析**   | 需求分析、用户旅程、流程设计       | 服务设计、产品经理   |
| **方案设计与迭代**   | 复杂问题拆解、假设验证、方案构建   | 咨询、产品、策略     |
| **图纸与可视化表达** | 信息设计、视觉叙事、概念表达       | UX、品牌、游戏/影视 |
| **多专业协同**       | 项目管理、跨团队沟通、风险协调     | 项目经理、产品运营   |
| **规范与政策研究**   | 规则研究、合规理解、结构化判断     | 地产、ESG、公共部门  |
| **汇报与提案**       | 商业表达、方案说服、客户沟通       | 咨询、销售、策划     |

## F4｜方向准备指南
| **内容模块**   | **必须回答的问题**                                                 |
|----------------|--------------------------------------------------------------------|
| **行业接受度** | 企业是否限制专业？哪些企业/团队更容易接受建筑背景？需要证明什么？ |
| **能力缺口**   | 已有能力可以直接使用哪些？必须补充哪些工具、方法或行业知识？       |
| **CV指南**     | 建筑项目如何转译为目标岗位语言？保留/删除哪些信息？如何写成果？   |
| **作品集指南** | 是否需要作品集？建筑项目能否改造？需要增加什么个人项目？           |
| **面试指南**   | 如何解释离开建筑、为什么选择目标岗位、如何证明能力迁移？           |
| **行动清单**   | 未来2周、1个月和3个月分别完成什么最小任务？                        |

## F5｜招聘机会
| **功能点**   | **需求说明**                                             | **优先级** |
|--------------|----------------------------------------------------------|------------|
| **岗位列表** | 仅收录与建筑能力迁移相关、仍在有效期内的公开岗位。       | P0         |
| **岗位标签** | 标记专业限制、作品集要求、经验要求、建筑适配能力和地点。 | P0         |
| **原始链接** | 跳转企业官网或可信招聘来源，平台不在MVP内接收简历。      | P0         |
| **路径关联** | 岗位关联相关方向、案例和材料准备指南。                   | P1         |
| **过期处理** | 岗位设有效期，到期自动隐藏，运营可复核恢复。             | P0         |

## F6｜咨询者与付费咨询
| **功能点**     | **需求说明**                                                                 | **优先级** |
|----------------|------------------------------------------------------------------------------|------------|
| **咨询者主页** | 展示匿名昵称、原背景概述、当前方向、擅长问题、服务、价格、可预约时间和评价。 | P0         |
| **后台认证**   | 平台验证真实身份与转行经历；认证信息默认不公开。                             | P0         |
| **文字咨询**   | 用户提交背景与1个核心问题；咨询者在约定期限内回答，可追加一次。              | P0         |
| **视频咨询**   | 选择30/60分钟时段，支付后生成第三方会议链接或由咨询者填写。                 | P0         |
| **材料诊断**   | 可选CV/作品集方向诊断；用户上传脱敏文件，仅订单双方可见。                   | P1         |
| **订单与退款** | 支持待确认、已付款、已完成、取消、退款申请等基础状态。                       | P0         |
| **评价**       | 完成后按专业性、针对性和沟通体验评分并留下文字评价。                         | P1         |

## F7｜用户账户与个人中心
- 手机号或邮箱登录；支持游客浏览，收藏和交易前要求登录。

- 收藏方向、案例、岗位和咨询者。

- 查看咨询订单、问题、回复、会议链接和评价状态。

- 管理上传的CV/作品集，支持主动删除。

- 管理个人探索信息；探索信息默认仅本人可见，不公开生成用户主页。

## F8｜运营后台
- 方向、能力标签、案例、指南和招聘岗位的创建、编辑、审核、发布和下架。

- 案例来源、授权、匿名化检查和敏感信息提示。

- 咨询者认证、服务审核、订单争议和评价管理。

- 举报、侵权、隐私删除请求和内容纠错处理。

- 基础数据看板：浏览、收藏、方向转化、咨询订单和内容缺口。

# 07 关键交互流程
## 流程A｜用户不知道可以转什么
> **1.** 进入首页，选择“我不知道可以转什么”。
>
> **2.** 填写当前身份、建筑相关年限和原岗位类型。
>
> **3.** 从能力标签中选择自己擅长或愿意继续使用的能力。
>
> **4.** 选择约束条件：是否愿意做作品集、是否可脱产、是否接受初级岗位、偏好行业。
>
> **5.** 系统基于规则展示3–8个候选方向，而不是给出唯一答案。
>
> **6.** 用户查看每个方向的适配依据、真实门槛和准备成本。
>
> **7.** 进入方向详情，继续查看案例、岗位和咨询者。
>
> **8.** 收藏目标方向，形成个人探索清单。

## 流程B｜用户已经有目标方向
> **1.** 搜索或选择目标方向。
>
> **2.** 查看行业接受度、工作内容和建筑背景的优劣势。
>
> **3.** 查看“我已经具备/我需要补充”的能力对照。
>
> **4.** 查看CV、作品集和面试准备建议。
>
> **5.** 阅读不同起点的转行案例，识别可复制和不可复制部分。
>
> **6.** 查看相关招聘岗位，验证市场真实需求。
>
> **7.** 选择自己可以立即完成的行动清单，或预约咨询者。

## 流程C｜付费文字咨询
> **1.** 用户进入咨询者主页，确认其擅长范围和服务边界。
>
> **2.** 选择文字咨询，填写当前背景、目标、已完成准备和1个核心问题。
>
> **3.** 按需上传脱敏CV或作品集；系统提示删除姓名、电话、邮箱和公司机密。
>
> **4.** 完成支付，订单进入“待回复”。
>
> **5.** 咨询者在承诺时限内回复；用户可追加一次问题。
>
> **6.** 咨询者完成补充回复，订单完成。
>
> **7.** 用户评价；文件到期自动删除或由用户提前删除。

## 流程D｜视频会议预约
> **1.** 用户选择30或60分钟服务及咨询主题。
>
> **2.** 填写背景、问题和期望结果，选择可预约时段。
>
> **3.** 支付后锁定时段，并收到确认通知。
>
> **4.** 咨询者或平台写入腾讯会议/Zoom等第三方链接。
>
> **5.** 会议前24小时和1小时发送提醒。
>
> **6.** 会议结束后双方确认完成；出现争议时进入平台处理。
>
> **7.** 用户评价，咨询者获得结算。

## 流程E｜案例投稿与发布
> **1.** 投稿者选择匿名程度和是否愿意提供咨询。
>
> **2.** 按照结构化模板填写转行路径，不要求提供与路径无关的私人经历。
>
> **3.** 在后台单独提交真实性证明；证明信息不进入公开案例。
>
> **4.** 运营编辑检查来源、事实、隐私、表达和可操作性。
>
> **5.** 投稿者预览公开版本并确认授权。
>
> **6.** 案例发布；投稿者可以后续申请修改或删除。

# 08 内容结构与隐私规则
## 结构化案例模板
| **模块**       | **公开关键信息**                           | **隐私处理**                       |
|----------------|--------------------------------------------|------------------------------------|
| **转行起点**   | 专业类别、岗位类型、经验区间、已有能力     | 不公开学校、精确公司、精确年份组合 |
| **机会与契机** | 如何发现行业、通过何种项目/课程/人脉进入 | 删除可识别个人关系和具体联系人     |
| **能力迁移**   | 哪些建筑能力被目标岗位认可、如何证明       | 只讲方法和项目类型，不公开客户机密 |
| **能力补充**   | 学习内容、工具、方法、准备周期             | 不要求展示课程账号或消费记录       |
| **CV与作品集** | 结构、项目选择、表达方式和常见错误         | 示例材料必须脱敏或重新制作         |
| **面试**       | 常见问题、回答逻辑、质疑点                 | 不公开面试官、内部题目或保密信息   |
| **结果与反思** | 进入方式、过渡岗位、最难部分和建议         | 收入只允许可选区间，不展示精确数字 |

## 数据最小化原则
- 公开展示以“路径方法”为最小必要信息，不以人物曝光为目标。

- 真实身份、证明材料和联系方式仅在后台审核系统中保存，并限制运营权限。

- 公开案例默认使用昵称或编号；公司、学校、城市和年份可按粒度模糊化。

- 咨询者可以选择公开当前行业和岗位类别，但不强制公开具体公司。

- 用户上传的CV/作品集只对订单双方可见，默认在订单完成30天后删除。

- 用户和投稿者拥有修改、撤回授权和删除公开内容的入口。

## 内容来源与授权
| **来源类型**             | **使用方式**                               | **要求**                           |
|--------------------------|--------------------------------------------|------------------------------------|
| **平台原创采访**         | 编辑整理为结构化案例                       | 取得受访者公开授权并确认匿名版本   |
| **用户主动投稿**         | 审核后发布                                 | 投稿协议、真实性声明、隐私选择     |
| **公众号/小红书等内容** | 优先获得授权转载；否则仅做短摘要和原文跳转 | 保留作者与来源，不复制全文         |
| **企业招聘信息**         | 提取与建筑转行相关字段并链接原始页面       | 记录来源和有效期，避免修改岗位原意 |
| **公开职业资料**         | 用于方向指南与能力词典                     | 由编辑改写和校验，不拼接成个人案例 |

## 禁止公开的内容
- 身份证件、手机号、私人邮箱、住址和未公开社交账号。

- 未经同意的真实姓名、精确公司、团队名称和可定位项目。

- 精确工资、家庭与感情情况、健康信息等与转行方法无关的信息。

- 客户图纸、合同、内部材料、未发布作品和面试保密内容。

- 对原公司、个人或行业的未经证实指控。

## 咨询者准入
- 完成真实身份验证，但公开页面允许使用昵称。

- 提供目标行业的工作证明或其他合理证明，由平台人工审核。

- 明确可回答与不可回答的问题，不允许承诺内推、录用或收入结果。

- 至少完成一份结构化转行案例或平台访谈。

- 接受服务规范、隐私要求、取消退款规则和评价机制。

## 交易与风控边界
- 平台收取订单服务费或佣金，具体比例在商业验证后确定。

- 咨询者不得在公开资料中诱导用户绕过平台交易。

- 服务只提供经验和建议，不承诺录用、内推、签证、学历或收入结果。

- 咨询者不得索取与咨询无关的敏感个人信息。

- 会议未发生、严重迟到或服务明显不符时，用户可提交退款申请。

- 涉及骚扰、歧视、虚假经历、侵犯隐私或知识产权的账户可暂停或永久下架。

| **品牌与商业策划**          | 建筑人具有空间、视觉和提案优势     | 概念、叙事、客户沟通           |
| **游戏/影视/AI视觉**      | 视觉与空间技能直接相关             | 建模、场景、概念表达           |
| **地产投资/资产管理**      | 行业知识延续，转行跨度相对可控     | 项目理解、市场与空间判断       |
| **咨询/研究**              | 研究、结构化和汇报能力可迁移       | 调研、分析、框架和提案         |
| **建筑科技/BIM/数字建造** | 最接近原行业，适合低风险转型       | 软件、流程、跨专业协同         |
| **可持续/ESG/城市研究**   | 政策、规范和系统思考具有价值       | 研究、规则、跨尺度分析         |

## MVP之后的可选迭代
- 基于用户收藏和行为的个性化方向排序，但仍展示推荐理由和不确定性。

- CV段落和项目经历的能力转译辅助，不直接代写整份材料。

- 作品集结构卡和案例拆解工具。

- 主题小组咨询、线上分享会和方向公开课。

- 企业认证岗位、人才专题和招聘合作。

- “蟑螂迁徙地图”年度报告，展示建筑人流向和能力趋势。

## 咨询问题提交模板
- 我的当前状态：专业/岗位类型/经验区间。

- 我的目标方向：已明确或正在比较的岗位。

- 我已经完成的准备：课程、项目、CV、作品集或投递。

- 我目前最大的障碍：方向、能力、材料、面试或求职机会。

- 我希望本次咨询获得的一个明确结果。

- 可选：上传脱敏后的CV或作品集。

> **最终产品判断标准**  
> 用户离开网站时，不一定已经决定辞职或转行，但应该至少获得一个更清楚的候选方向、一套能力迁移解释，以及一个可以立即执行的下一步。

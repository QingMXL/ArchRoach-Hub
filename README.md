## 这是什么

一个面向建筑学学生与从业者的职业探索工具的**前端原型**：把分散在各处的转行信息，整理成可筛选、可比较、可行动的结构化内容——转行方向、真实案例、能力迁移词典、招聘与资源，以及向已经走过这条路的人预约一次咨询。

产品定义与内容规则来自 [`docs/SPEC_建筑蟑螂互助会_PRD与MVP_v1.0.md`](docs/SPEC_建筑蟑螂互助会_PRD与MVP_v1.0.md)，视觉体系来自 [`docs/design-system.md`](docs/design-system.md)。

### 请先了解（避免误解）

- 这是**纯前端静态原型**，没有后端、没有数据库、没有账号系统。
- 页面里的方向、案例、前辈、岗位、订单、消息**全部是写在 `assets/js/data-*.js` 里的示例数据**，不是真实的人、岗位或经历。
- 预约下单流程（选服务 → 选时段 → 填信息 → 确认 → 支付）是**界面演示**，不会产生任何真实交易；点击「支付」只切换到成功状态。
- 收藏与语言偏好保存在浏览器 `localStorage`，换设备不同步。
- 案例封面、前辈头像都是**内联 SVG 生成的插画**，不是照片。

## 交互

- **全局搜索**：`⌘K` / `Ctrl K` 唤起，结果按「方向 / 案例 / 前辈 / 岗位」分组。
- **筛选**：胶囊筛选器即时生效，只重渲染结果区，不刷新整页。
- **收藏**：方向 / 案例 / 前辈可收藏，汇总在个人中心收藏夹。
- **页面转场**：统一的顶部进度条 + 分段浮现动画，所有路由一致。
- **响应式**：≤1100px 侧栏变抽屉；1440 / 1024 / 390 三档实测无横向溢出。
- **动效降级**：`prefers-reduced-motion` 下关闭全部动画与平滑滚动。

## 技术实现

刻意保持简单，**没有框架、没有构建步骤、没有依赖**：

- 原生 HTML / CSS / JavaScript（ES5 风格，全部为经典 `<script>`，不用 ES Module）
- hash 路由 + 字符串模板渲染 + 事件委托
- 设计令牌集中在 `assets/css/tokens.css`
- 所有图形（蟑螂角色的 12 种姿势、45 个图标、案例封面）都是内联 SVG，零外部请求
- 因为不用 ES Module 与 `fetch`，**直接双击 `index.html` 也能打开**

### 目录

```
index.html                 应用外壳：侧栏 + 顶栏 + SVG 雪碧图
assets/css/
  tokens.css               设计令牌（颜色 / 字号 / 间距 / 圆角 / 阴影 / 动效）
  base.css                 reset、工具类、转场、Toast
  layout.css               App Shell、侧栏、顶栏、内容骨架
  components.css           按钮、文件夹卡、内容卡、筛选胶囊、表单、空状态
  pages.css                各页面专属样式
assets/js/
  i18n.js                  中英词典与切换
  data-*.js                示例数据（方向 / 能力 / 案例 / 前辈与岗位）
  ui.js                    渲染原子（图标、蟑螂、文件夹卡、收藏）
  art.js                   案例封面 SVG
  page-*.js                各页面渲染与交互
  app.js                   路由、全局搜索、抽屉、语言切换
docs/                      产品 SPEC、设计系统、设计参考图
screenshots/               README 用截图
```

## 本地运行

直接打开即可：

```bash
open index.html
```

需要 `?lang=` 之类的 URL 参数或想更接近线上环境，起个静态服务器：

```bash
python3 -m http.server 4173
# 然后访问 http://localhost:4173/
```

无需 `npm install`。

## 设计系统要点

- **底色是冷灰白**，不是暖色。画布 `#F1F1F4`，应用容器纯白、30px 圆角、大阴影，像一个独立的数字工作台。
- **蟑螂棕 `#B9632E` 只占约 7%**：主按钮、Logo、少量强调。品牌色不铺满页面。
- **文件夹卡片**承载一级内容集合：左上角标签页与主体是一体轮廓，hover 时标签页轻微上抬。
- **低饱和粉彩**只用于分类识别（淡紫 = 方向、淡蓝 = 案例、淡桃 = 咨询、淡绿 = 学习、淡玫瑰 = 机会）。
- **蟑螂是品牌组件不是表情**：12 种姿势（挥手、指路、拿放大镜、抱文件夹、庆祝、戴领带 / 眼镜 / 帽子…），用于 Logo、引导、空状态与前辈头像。

完整规范见 [`docs/design-system.md`](docs/design-system.md)。

## 内容与隐私原则

来自 SPEC，原型里也照此实现：

- 案例只公开类别与区间（专业类别、经验区间、准备周期），不公开学校、精确公司与精确薪资。
- 前辈使用昵称与角色形象，不使用真实姓名与照片。
- 上传的 CV / 作品集在文案上明确「仅订单双方可见、30 天后删除」。

## 已验证 / 未验证

**做过的检查**

- 12 条路由在中文与英文下渲染 + 挂载均无异常，控制台无报错或警告
- 数据交叉引用完整性检查（案例 ↔ 前辈 ↔ 方向 ↔ 岗位）全部通过
- 1440 / 1024 / 390 三档视口无横向溢出
- 筛选、搜索、标签页、收藏、四步预约流程逐项手动验证

**没做的**

- 没有自动化测试（无单元测试 / E2E）
- 只在 macOS Chrome 上测过，未做跨浏览器验证
- 没有做系统性的无障碍审计（有键盘可达、`aria-*`、focus-visible、reduced-motion，但没跑过 axe 之类的工具）
- 没有性能基准（无构建、无压缩，资源都是未优化的源文件）
